## Publish in a new, dedicated public GitHub repository
- This package must not be merged into or deployed as the original sf6-ai-coach-viewer production site.
- The owner first creates a separate empty repo (suggested sf6-b1-safari-probe) under their own GitHub account. A repo-creation tool is not currently available to this assistant.
- Add public/index.html, public/.nojekyll, and .github/workflows/pages.yml from this package to its main branch. They contain NO token, no private video, no OAuth ID. public/sample.mp4 is generated by the dedicated repo's Actions workflow, not committed.
- GitHub repo Settings > Pages > Build and deployment > Source: GitHub Actions. Run the staging workflow if it did not automatically trigger.

- First press 「30fps合成テスト動画を開く」. Confirm JavaScript initialization status, loadedmetadata, canplay, actual playback, 3 seconds of playback -> pause -> next/next/previous frame. Copy only text observations.
- Only after the synthetic test should the owner optionally select an existing local MP4 to probe local decoding and seeking. Video is never uploaded. CSP denies outgoing connect-src.
- Mark PASS only from actual visible video changes while paused; time-code movement alone is not conclusive.
- B0 YouTube unlisted library remains a separate Google OAuth proof-of-concept, NOT included.
